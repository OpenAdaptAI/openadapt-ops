# Contributing and research

These pages are for contributors and researchers. You don't need them to
evaluate, install, or run OpenAdapt.

| Page | What it covers |
|---|---|
| [Product components and release admission](../ecosystem/index.md) | The public repositories behind the product, their roles, and the live Production state of each release. |
| [Documentation source of truth](../reference/documentation-governance.md) | Which repository deploys this site, and which historical documentation trees must not. |
| [Seal as an RL reward](../commercial/seal-reward.md) | Research on using a Seal's verified outcome as a reward signal for training. |
| [Technical paper source](https://github.com/OpenAdaptAI/openadapt-flow/tree/main/paper) | The paper draft, its benchmark constants, methods, and limits. |

To contribute code or docs, read
[CONTRIBUTING.md](https://github.com/OpenAdaptAI/OpenAdapt/blob/main/CONTRIBUTING.md)
in the repository you're changing. Each commit carries a `Signed-off-by` line
under the Developer Certificate of Origin.
