Showcase animation provenance
=============================

The showcase animation shows a real application running synthetic data. It is
not a mock application, and it is not a hand-drawn or scripted mock-up. Public
material never uses an in-house stand-in application; those are for internal
testing.

Unlike docs/assets/ui, this file is not a byte-identical vendored copy. It is
composed here from media that OpenAdaptAI/openadapt-web publishes, by
scripts/build_showcase_animation.py in this repository. That script reads the
pack manifest and renders no claim the manifest does not state. Rebuild it with:

  uv run --with pillow python scripts/build_showcase_animation.py \
      --pack <openadapt-web>/public/reference/openimis-eligibility-standard-synthetic-v1
  uv run --with pillow python scripts/measure_asset_palette.py --write

  0 off-box transmissions, and 0 observed silent incorrect successes. No
  customer, patient, or production record appears in any frame; every insuree,
  policy, and date is fixture data from the pack's synthetic database.

  Three media files supply every screen, sampled and scaled but not otherwise
  altered. The animation adds only chrome: a caption panel, a header, a footer,
  and the opening card, all drawn in canonical tokens read from
  docs/stylesheets/vendor/openadapt-web/tokens.json.

  Read the measurement in docs/assets/visual-palette.json with one thing in
  mind: scripts/measure_asset_palette.py samples an animation's first frame
  only, and the first frame here is the opening card. The recorded #0b1220 is
  therefore the composition's own --inset-bg, not an openIMIS screen. The
