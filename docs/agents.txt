## How to call

Walkthrough for agents: https://docs.openadapt.ai/get-started/agent-mcp/

```
claude mcp add openadapt -- uvx --python 3.12 openadapt-agent serve
```

That is the sandbox. To have the real engine drive the synthetic MockMed app:

```
claude mcp add openadapt -- uvx --python 3.12 --from 'openadapt-agent[tutorial]' openadapt-agent serve
```

Your own compiled workflows: `openadapt-agent serve --mode production --bundles DIR --runs-dir RUNS`. `--allow-run` is the older form of `--mode production`.

The engine on its own:

```
python -m pip install --upgrade openadapt
openadapt flow tutorial
openadapt quickstart --break-it
```

Never summarize halt as success.

## Outcome vocabulary

MCP `outcome`: `done` | `needs_review` | `not_sure_if_saved` | `did_not_run`, and `running` while a run is in progress. Branch on `outcome` and `safe_to_retry`.

Engine `transaction_outcome`: `VERIFIED` | `HALTED_BEFORE_EFFECT` | `RECONCILIATION_REQUIRED` | `REJECTED_POLICY` | `CANCELED` | `FAILED_PLATFORM` | `COMPLETED_UNVERIFIED` | `ROLLED_BACK`. Engine `execution_outcome`: `VERIFIED` | `COMPLETED_UNVERIFIED` | `HALTED` | `FAILED` | `ROLLED_BACK`.

`VERIFIED` (`done`) means the declared result checks passed through a read independent of the acting screen. Halt is not success. If delivery is uncertain after an action may have been dispatched, the outcome is `RECONCILIATION_REQUIRED` (`not_sure_if_saved`). Do not retry it; a person checks the record.

Read `report.json` and the seal. `REPORT.md` is for humans.

## Escalation

Halt packets with typed agent-continue are not shipped this week.

- Missing declared parameter: calling agent, if the schema allows it.
- Retryable transport: agent, inside policy, same idempotency key.
- Identity, effect contradiction, expired policy, novel UI, admission: human.

Do not resolve identity or effect contradictions yourself. Do not fabricate a success path.
